# Browser

![Supports aarch64 Architecture][aarch64-shield] ![Supports amd64 Architecture][amd64-shield]

Browser control for Assist conversation agents over MCP. A Chromium browser
driven by [Playwright MCP](https://github.com/microsoft/playwright-mcp):
navigate, click, fill forms, take screenshots and upload files from
`/share`. When a site needs a login, do it yourself in the sidebar panel and
the agent continues in the same browser.

## Quick start

1. Install **Browser** from the app store and click **Start**.
2. Add the discovered **Model Context Protocol** integration under
   **Settings → Devices & services**.
3. Enable the tools for your Assist conversation agent and ask it to open a
   page, read it or take a screenshot.
4. For sites that need a login, open **Browser** in the sidebar and log in
   there first.

See **[DOCS.md](DOCS.md)** for tools, the panel, options and the security
notes.
